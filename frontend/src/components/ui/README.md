This folder contains small UI primitives generated from the design system.

- `Button.tsx` — Primary/secondary button that uses CSS custom properties from `index.css`.
- `HeroVideo.tsx` — Video-first hero section with overlayed CTA.

Usage example:

```tsx
import HeroVideo from '../components/ui/HeroVideo'

export default function Home() {
  return (
    <main>
      <HeroVideo videoSrc="/assets/hero.mp4" title="Welcome" subtitle="Try the new DashB experience" />
    </main>
  )
}
```

You can edit the CSS tokens in `src/index.css` under the `:root` block generated by the design system.
